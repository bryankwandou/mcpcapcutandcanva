# Fitur Canva & CapCut: Free, Pro, dan di Rakit Studio

> Status Free/Pro diambil dari informasi publik per Oktober 2026 dan bisa berbeda per wilayah atau berubah sewaktu-waktu. Cek ulang di aplikasi Canva/CapCut Anda. Terakhir diperbarui 2026-10-02.

Kolom **Paket** = paket yang dibutuhkan di aplikasi aslinya. Kolom **Rakit** = ketersediaan di Rakit Studio.

| Status | Arti |
|---|---|
| ✅ Ada | Ada di Rakit Studio dan berfungsi |
| 🟡 Sebagian | Ada sebagian |
| 🔗 Lewat akun Anda | Lewat akun Anda sendiri (Canva API / aplikasi CapCut) |
| ❌ Tidak | Tidak tersedia |
